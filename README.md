# TaskBloom

TaskBloom is a simple, responsive to-do app built with HTML, CSS, and vanilla JavaScript. It helps you keep track of tasks in a calm, pastel-themed interface.

## Run the app

1. Open the project folder in VS Code.
2. Open `index.html` in a browser (or use VS Code's **Open with Live Server** option if you have that extension installed).

No build step, server, or package installation is required.

## Features

- Add, complete, and delete tasks.
- Filter tasks by All, Active, and Done.
- View task counts and completion progress.
- Clear completed tasks.
- Save tasks and theme preference in your browser's local storage.
- Switch between light and dark themes.
- Contact the developer by email or visit the GitHub profile using the footer links.

## Project files

- `index.html` — page structure and accessible controls.
- `style.css` — layout, responsive styles, animations, and light/dark themes.
- `script.js` — task management, filters, notifications, and local storage.

Task data and theme preferences are stored in the current browser. Clearing that browser's site data will remove them.
